# Contributing

Thanks for helping improve Stepwise.

## Development

Use Swift Package Manager:

```sh
swift build
swift test
```

Keep `StepwiseCore` independent of SwiftUI and optional extraction APIs. Keep examples generic and avoid app-specific concepts.

## Pull requests

- Prefer small, focused changes.
- Add tests for model, validation, normalization, extraction parsing, and UI initializer coverage.
- Update docs when public APIs change.
